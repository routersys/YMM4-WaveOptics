波動光学 for YMM4

YukkuriMovieMaker4（YMM4）の映像エフェクトプラグインです。円形または正多角形の開口と、ゼルニケ多項式の波面収差から点像分布関数を求めて、素材に畳み込みます。点のような光は、羽根の枚数に応じた光条や、開口の形をした玉ボケになります。

最新版をダウンロード / ソースコード / README

概要

写真に写る光は、1点が1点にならずに小さく広がります。広がり方を決めるのは、光が開口の縁を回り込む回折と、波面が理想の形からずれる収差です。本プラグインは、この広がりを式で計算して、素材のすべての画素の光に与えます。

広がり方は、開口の形、中央遮蔽、6種類の波面収差、波長、F値、画素ピッチの設定だけで決まります。履歴フレーム、参照画像、学習済みモデルは使わず、入力された1枚の映像だけを処理し、同じ機器で同じ経路なら、同じ素材と同じ設定から、いつも同じ結果になります。

画像

境目を左右に動かして、素材と適用後を見比べられます。素材は、合成した1920×1080の夜景から、中央の1600×900を切り出したものです。適用後の設定は、F値16、画素ピッチ2μm、カーネル半径63画素、6枚羽根の正多角形の開口で、線形光はオン、ハイライトの強さは30倍です。設定の全体は作例のページにあります。

主な機能

  • 開口は円形か正多角形を選びます。正多角形は羽根枚数と開口回転を指定でき、中央遮蔽も指定できます。
  • 波面収差は、デフォーカス、縦横非点収差、斜め非点収差、水平コマ収差、垂直コマ収差、球面収差の6項目です。
  • 線形光、ハイライト、ディザを使えます。光の強さに比例する値で畳み込み、頭打ちの光を持ち上げ、8ビットに丸めるときの光の損失を抑えます。
  • 適用量、利得、ハイライトの2項目、波長、F値、画素ピッチ、開口回転、中央遮蔽、波面収差の6項目の、計15項目がアニメーションに対応しています。
  • 畳み込みはGPUで計算し、計算し直したフレームごとに結果を検査します。検査で誤りを見つけたときと、GPUを使えないときは、CPUで計算します。
  • 品質は高速、標準、高精度の3段階です。画面は8言語に対応しています。

導入

  1. Releasesのページから、最新のプラグインファイル（.ymme）をダウンロードします。
  2. YMM4を終了してから、ダウンロードしたファイルを実行してインストールします。
  3. YMM4を起動して、タイムライン上のアイテムに映像エフェクトを追加します。
  4. 映像エフェクトの種類として「波動光学」を選びます。カテゴリは加工です。

追加した直後は、映像がわずかにやわらぐだけです。にじみを大きくする方法は設定の選び方にあります。

動作要件

項目要件
OSWindows 10 バージョン2004（ビルド19041）以降、またはWindows 11（64bit）
YukkuriMovieMaker4最新版を推奨します
ランタイム.NET 10.0
GPUDirect3D 12と、Direct3D 11・12間の共有テクスチャおよび共有フェンスを使えるGPUを推奨します。使えない場合は、CPUで計算します

制限事項

  • 素材は8ビットなので、光源の画素の値は1.0で頭打ちになります。光条のような弱い光を見せるには、線形光とハイライトを使います。ハイライトは、光源の本当の明るさを復元せず、指定した倍率で光を足す処理です。
  • 計算は単色光に限ります。赤、緑、青を同じ形で広げるので、虹色のにじみは出ません。
  • 広がりの形は画面のどこでも同じです。奥行きに応じて変わるボケは扱いません。
  • 広がりは、中心から最大63画素までです。画素数の多い素材では、映像の全体に対してにじみが小さく見えます。
  • 新しい版の確認と不具合の自動送信のために、通信を行います。送る内容は確かめ方のページにあります。
